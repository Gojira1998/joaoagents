Como funciona

Um time, não uma ferramenta

Cada agente é um arquivo de instruções com uma função só. Juntos eles tocam a rotina sem eu ficar em cima.

01

1 agente = 1 função

Palavras AGENTE e GUILDA

Kit da Guilda: 3 skills e 6 prompts pra quem está começando

Três skills pra começar o seu time de agentes e seis prompts pra colar no Claude Code, cada um com o primeiro passo.

Comece por uma skill e um prompt. Confira sempre o repositório oficial antes de instalar.

Skill 1: find-skills

Você descreve o que quer fazer e ela procura, no ecossistema aberto de skills, uma que já resolva. Evita você montar do zero o que já existe.

Link oficial: github.com/vercel-labs/skills, pasta find-skills.

Primeiro passo: npx skills add vercel-labs/skills --skill find-skills e depois pergunte: "existe uma skill pra organizar minhas planilhas?"

Skill 2: Karpathy Guidelines

Um plugin com regras simples de comportamento pro Claude: pensar antes de codar, fazer o mínimo necessário, mexer só no que foi pedido e dizer como vai conferir o resultado. Reduz aqueles erros de agente que sai alterando o que não devia.

Link oficial: github.com/multica-ai/andrej-karpathy-skills

Primeiro passo: no Claude Code, /plugin marketplace add forrestchang/andrej-karpathy-skills e depois /plugin install andrej-karpathy-skills@karpathy-skills

Skill 3: grill-me

Antes de executar um plano, o Claude te entrevista, uma pergunta por vez, até vocês dois terem a mesma ideia do que precisa ser feito. É ótima pra não gastar limite construindo a coisa errada.

Link oficial: github.com/mattpocock/skills, pasta skills/productivity/grill-me.

Primeiro passo: siga a instalação do README e diga: "me entreviste sobre o meu plano de [seu plano]".

Prompt 1: criar o seu primeiro agente

Copie, troque o que está entre colchetes e cole no Claude Code:

Quero criar um agente que cuida de [tarefa que se repete, ex.: responder orçamentos]. Antes de criar, me faça até 5 perguntas, uma por vez, sobre como eu faço essa tarefa hoje. Depois crie o agente como um arquivo na pasta .claude/agents com nome, descrição de quando usar e instruções claras do que ele faz e do que NÃO faz.

Prompt 2: o arquivo de memória do projeto

Leia esta pasta e crie um arquivo CLAUDE.md na raiz com: o que é este projeto, como se chama cada pasta, as regras que devo seguir sempre e o que nunca deve ser alterado. Máximo de 40 linhas, em português, sem enrolação.

Prompt 3: plano antes de executar

Não escreva nem altere nada ainda. Quero [objetivo]. Me entregue um plano em passos numerados, o que cada passo muda, o que pode dar errado e como vamos conferir que deu certo. Espere eu dizer "pode fazer" pra começar.

Prompt 4: transformar tarefa repetida em skill

Eu faço esta tarefa toda semana: [descreva em 3 frases]. Transforme isso numa skill: pergunte o que faltar, escreva o SKILL.md com quando usar, passo a passo e um exemplo de entrada e saída, e me diga em qual pasta salvar.

Prompt 5: revisar o que o agente fez

Releia o que você acabou de fazer como se fosse outra pessoa revisando. Liste o que pode estar errado, o que você supôs sem confirmar e o que eu devo conferir com os meus próprios olhos antes de usar. Seja direto, sem elogiar o próprio trabalho.

Prompt 6: economizar limite

A partir de agora, responda curto, sem repetir o que eu já disse e sem listar opções que eu não pedi. Se a tarefa for grande, divida em partes e me pergunte antes de começar a próxima. Quando a conversa ficar longa, me avise e resuma o essencial pra eu abrir uma sessão nova.

Palavra SÉRIE

Série de desenho sem câmera: o passo a passo

O caminho que eu uso na série dos goblins: roteiro, voz, imagens, animação em código e o truque que faz o pessoal comentar.

Faça um episódio curto primeiro (uns 60 segundos). Confira as condições de cada ferramenta na sua conta antes de começar.

1. Roteiro com o Claude

Funciona no app do Claude. Copie, troque o que está entre colchetes e cole:

Você é roteirista de uma série curta pro Instagram (reel vertical de 60 a 80 segundos). Série: [nome e mundo da série]. Personagens fixos: [nome e jeito de cada um]. O episódio anterior terminou assim: [resumo]. Personagens novos deste episódio, de quem comentou no último: [@ e o que cada pessoa pediu]. Escreva a narração em texto corrido, no máximo 180 palavras, nesta ordem: 1) um fato com número real (ex.: quantos seguidores a conta tinha ontem e tem hoje); 2) o evento da noite; 3) os personagens novos entrando, cada um com uma tarefa; 4) um problema que cresce; 5) uma pista ou reviravolta; 6) "comenta o personagem que você quer ser e segue a conta"; 7) uma frase de teaser do próximo episódio. Depois, faça a lista de cenas: o que aparece na tela em cada frase.

2. Voz no Google AI Studio (Gemini TTS)

Entre em aistudio.google.com e abra a geração de fala. Escolha a voz (na série dos goblins eu uso a Algieba; neste reel, a Fenrir).

No campo de estilo, diga como a voz deve soar. Exemplo: Narrador calmo e seco, meio entediado, pausas curtas entre as frases.

No texto, as tags <sigh> (suspiro), <laugh> (risada) e <gasp> (susto) dão vida à fala. Gere o texto inteiro de uma vez, assim a voz não muda no meio, e baixe o áudio.

3. Imagens no Google Flow

Entre em labs.google/flow. No meu plano, gerar imagem não gasta crédito; vídeo gasta, então eu só faço imagem e animo no código.

Prompt de estilo pra colar no fim de toda cena: 16-bit pixel art, isometric 3/4 view, [a cena], dark purple and moss green palette, orange accent light, vertical 9:16, no text, no letters, no watermark.

Personagem sempre igual: gere uma imagem boa dele, depois anexe essa imagem como referência em todo prompt novo e escreva "same character as the reference". Pra recortar o personagem depois, peça fundo de uma cor só, como magenta.

4. Animação em código com a skill HyperFrames

Projeto aberto da HeyGen (licença Apache-2.0): o vídeo vira uma página HTML animada e é renderizado em MP4 no seu computador. Precisa do Node.js instalado.

Link oficial: github.com/heygen-com/hyperframes

No Claude Code: claude plugin marketplace add heygen-com/hyperframes e depois claude plugin install hyperframes@hyperframes. Em outros agentes: npx skills add heygen-com/hyperframes

Depois peça: Use a skill hyperframes. Monte um vídeo vertical 1080x1920 com as imagens da pasta [pasta] e o áudio [arquivo]. Cada frase da narração é uma cena: [lista de cenas]. Legenda de até 3 palavras embaixo, zoom lento em cada imagem, efeitos de som baixos e a voz sempre na frente. Renderize em MP4.

5. O segredo: quem comenta entra na história

No fim de cada episódio, peça: "comenta o personagem que você quer ser". No episódio seguinte, quem comentou aparece com o @ em cima da cabeça, vestido do jeito que pediu.

Foi isso que fez a série dos goblins andar: a conta começou com zero seguidores e, em três dias, 83 pessoas pediram pra virar personagem. Responda cada comentário e lembre a pessoa de seguir pra se achar no próximo.

Palavra PLUGIN

Os 5 plugins pra parar de bater limite no Claude

O que cada um faz, o link oficial e o primeiro passo pra começar.

Confira sempre o repositório oficial antes de instalar. Comece por um só e teste por alguns dias.

OmniRoute

Um gateway gratuito de código aberto: você usa um endereço só e ele reparte o trabalho entre vários provedores de IA, inclusive opções grátis. É o que ajuda quando o limite de um acaba.

Link oficial: github.com/cheaper-inference/OmniRoute

Primeiro passo: siga a instalação do README do projeto.

Claude Mem

Guarda o que o Claude fez em cada sessão e traz o que importa de volta na próxima, pra você não explicar tudo de novo.

Link oficial: github.com/thedotmack/claude-mem

Primeiro passo: siga a instalação do README do projeto.

Headroom

Comprime logs, arquivos e saídas de ferramentas antes de chegarem ao modelo. Menos texto enviado significa menos consumo do seu limite. O percentual de economia é do próprio projeto, eu não medi.

Link oficial: github.com/headroomlabs-ai/headroom

Primeiro passo: siga a instalação do README do projeto.

Claude Code Setup

Plugin oficial da Anthropic. Ele analisa o seu projeto e recomenda automações sob medida: hooks, skills, servidores MCP e subagentes.

Link oficial: github.com/anthropics/claude-plugins-official, pasta claude-code-setup.

Primeiro passo: siga a instalação do README e peça pra ele analisar o seu projeto.

Task Observer

Observa como você usa suas skills e sugere melhorias nelas. Nada muda sem a sua aprovação. É o menos conhecido da lista.

Link oficial: github.com/rebelytics/one-skill-to-rule-them-all

Primeiro passo: npx skills add rebelytics/one-skill-to-rule-them-all --skill task-observer

Palavra SKILL

As 5 skills do Claude que eu mais uso

Pra que serve cada uma, o link oficial e o primeiro passo pra começar.

Comece por uma só e use por uma semana antes de pegar a próxima.

humanizer

Tira o jeito de texto de robô do que o Claude escreve. Use no fim, com o texto já pronto.

Link oficial: github.com/blader/humanizer

Primeiro passo: npx skills add blader/humanizer

frontend-design

Ajuda o Claude a criar site e telas com direção de arte, sem cara de template.

Link oficial: github.com/anthropics/skills, pasta frontend-design.

Primeiro passo: siga a instalação do README e peça "faça uma página para o meu negócio".

caveman

Faz o Claude responder curto, sem enrolação. Os autores falam em economia grande de texto; esse número é do projeto, eu não medi. Pra voltar ao normal, peça "normal mode".

Link oficial: github.com/JuliusBrussee/caveman

Primeiro passo: siga a instalação do README do projeto.

hyperframes

Você pede e o Claude monta o vídeo em código, sem abrir editor. Comece com um vídeo de uns 10 segundos, só com texto.

Link oficial: github.com/heygen-com/hyperframes

Primeiro passo: npx skills add heygen-com/hyperframes

skill-creator

A skill que cria skills. É o item do chefão: você explica uma tarefa repetida uma vez e ela vira uma skill sua.

Link oficial: github.com/anthropics/skills, pasta skill-creator.

Primeiro passo: siga a instalação do README e diga: "crie uma skill para esta tarefa que eu faço toda semana".
