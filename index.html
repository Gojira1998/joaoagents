0 de 3 derrotados

A IA que esquece tudo

Toda conversa nova começa do zero. Você explica de novo o seu jeito de escrever, as regras do cliente, o passo a passo.

O que derrota: uma skill. É uma pasta com instruções que o Claude só abre quando a tarefa pede.

O texto com cara de robô

Você pede um post e volta aquele texto liso, cheio de mania de IA. Ninguém acredita, e dá trabalho reescrever.

O que derrota: a skill que caça essas manias e deixa o texto com a sua voz.

A tarefa que volta toda semana

Aquela coisa que você faz sempre do mesmo jeito e ninguém automatizou. Ela come horas que eram do seu negócio.

O que derrota: criar a sua própria skill. Você explica uma vez, e o Claude não esquece mais.

Reel 1, palavra SKILL

As 5 skills do Claude que eu mais uso

Pra que serve cada uma, o link oficial e o primeiro passo pra começar.

Comece por uma só e use por uma semana antes de pegar a próxima.

humanizer

Tira o jeito de texto de robô do que o Claude escreve. Use no fim, com o texto já pronto.

Link oficial: github.com/blader/humanizer

Primeiro passo: npx skills add blader/humanizer

frontend-design

Ajuda o Claude a criar site e telas com direção de arte, sem cara de template.

Link oficial: github.com/anthropics/skills, pasta frontend-design.

Primeiro passo: siga a instalação do README e peça "faça uma página para o meu negócio".

caveman

Faz o Claude responder curto, sem enrolação. Os autores falam em economia grande de texto; esse número é do projeto, eu não medi. Pra voltar ao normal, peça "normal mode".

Link oficial: github.com/JuliusBrussee/caveman

Primeiro passo: siga a instalação do README do projeto.

hyperframes

Você pede e o Claude monta o vídeo em código, sem abrir editor. Comece com um vídeo de uns 10 segundos, só com texto.

Link oficial: github.com/heygen-com/hyperframes

Primeiro passo: npx skills add heygen-com/hyperframes

skill-creator

A skill que cria skills. É o item do chefão: você explica uma tarefa repetida uma vez e ela vira uma skill sua.

Link oficial: github.com/anthropics/skills, pasta skill-creator.

Primeiro passo: siga a instalação do README e diga: "crie uma skill para esta tarefa que eu faço toda semana".
