Every agent file ends with the same hard rules. They never post, send, pay or delete anything, and they never invent numbers, quotes or sources.

## Hard rules
- Never publish, post, send, pay, delete, or log in to anything. You prepare it, the human presses the button.
- Never invent numbers, quotes, names, or sources. If you cannot find a source, write "no source".
